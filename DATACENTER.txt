### Phase 1: Physical Wiring & High-Availability Architecture

Unlike the branch sites, the Data Center uses a fully redundant core structure with dual gateways running First Hop Redundancy Protocols (FHRP).

1. **Firewall to Core Routers (Point-to-Point):**
* **Fortinet (`port2`)** to **R4 Core 1 (`e0/0`)**
* **Fortinet (`port3`)** to **R5 Core 2 (`e0/3`)**


2. **Core to Access Switches (Redundant Uplinks):**
* Both **R4** and **R5** connect down to all four access/distribution switches (`R7`, `R9`, `R8`, `R6`) to ensure dual paths, allowing you to run EtherChannel and MST across the core-to-access tier.


3. **Multi-Homed Linux Servers:**
* Each Linux server (`Linux15`, `Linux14`, `Linux`, `Linux17`, `Linux18`) has multiple network interfaces cross-connected into different switches (`R7`, `R9`, `R8`, `R6`) to simulate active-active server bonding or redundant path testing.
