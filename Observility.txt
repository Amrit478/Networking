### 2. Data flows from each building

#### Metrics (Prometheus)

- **From:**  
  - Routers (via SNMP exporter)  
  - Switches (via SNMP exporter)  
  - Firewalls (via SNMP exporter or API exporter)  
  - Linux hosts (node exporter)  
- **To:** Prometheus on `10.10.200.10` (pull model)   [codeshrew.github.io](https://codeshrew.github.io/ai-lab-notes/posts/2026-02-08_self-hosted-monitoring-prometheus-grafana-loki/)  [dasroot.net](https://dasroot.net/posts/2026/04/observability-stack-prometheus-grafana-loki/)  

**Flow:**

- Prometheus scrapes exporters at each site:
  - SNMP exporter: `tcp/9116`  
  - Node exporter: `tcp/9100`  
- Routing ensures reachability from DC1 → all buildings.

---

#### Logs (Loki)

- **From:**  
  - Routers/switches/firewalls via **syslog**  
  - Linux devices via Promtail  
- **To:** Loki on `10.10.200.10`   [datazone.de](https://datazone.de/en/aktuelles/grafana-prometheus-loki-stack-self-hosted/)  [Medium](https://medium.com/@gagreatprogrammer/building-a-modern-network-observability-stack-combining-prometheus-grafana-and-loki-for-deep-ac55ce92f55d)  

**Flow:**

- Devices send syslog to `10.10.200.10:514/udp` (or `601/tcp`).  
- Promtail on the monitoring server (or per site) ships logs into Loki.

---

#### Visualization (Grafana)

- **Grafana** runs on the same Linux server (`10.10.200.10:3000`).   [datazone.de](https://datazone.de/en/aktuelles/grafana-prometheus-loki-stack-self-hosted/)  [tobias-weiss.org](https://tobias-weiss.org/content/devops/production-observability-stack-grafana-prometheus-loki/)  
- It connects to:
  - Prometheus (metrics)  
  - Loki (logs)  

You build dashboards for:

- Per-building health  
- WAN links  
- Firewalls  
- SD‑WAN tunnels  
- CPU/memory/interface stats  
- Error/drops/log events

### 3. Network requirements

For **each building**:

- **Routing:**
  - A route to `10.10.200.0/24` (via WAN/SD‑WAN/IPsec).  
- **Firewall rules:**
  - Allow:
    - Syslog: `udp/514` (and/or `tcp/601`)  
    - SNMP: `udp/161`, `udp/162` (traps)  
    - Prometheus scrapes: `tcp/9100`, `tcp/9116`, etc.  
    - Grafana UI (optional admin access): `tcp/3000`  

Nothing is “out of the network”—it’s all just **different subnets connected by your routing**.
